Clutch's file is linked by its official help center at
https://help.clutch.co/en/knowledge. G2's file is used by its official brand page
https://company.g2.com/brand-resources. ProvenExpert's file is used by its public
website. Sortlist's asset path is its published Organization/Brand logo; despite
the source filename, the delivered artwork is dark `#0F0D0A`, suited to a light
background.

The Manifest file is an unchanged third-party mirror of its burgundy overlapping
frames and black/burgundy wordmark, from
https://www.stickpng.com/img/icons-logos-emojis/tech-companies/the-manifest-logo.
Direct access to The Manifest's website returned HTTP 403; the Brandfetch mirror
redirected to HTML and was not used. This is a logo-only identification link,
not a claim of being a Manifest award winner. The mirror does not confer new
trademark rights; the trademark remains The Manifest's.

SVGs were parsed and inspected for script elements, event handlers, foreign
objects, and external resource references. PNGs were decoded and visually
inspected to ensure they contain the expected platform artwork.
